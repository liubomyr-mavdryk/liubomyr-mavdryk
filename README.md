### the stack, unfiltered

I pick tools that the team 12 months from now won't curse me for.

| layer | tools | why |
|---|---|---|
| backend | Node.js, NestJS, Express, TypeScript, GraphQL, WebSockets | modular, typed, boring in the good way |
| frontend | React, Next.js, Redux Toolkit, React Query, Zustand, Tailwind, MUI | right rendering strategy first, bundle size second |
| data | PostgreSQL, MySQL, MongoDB, Redis, Prisma | understand the query before you optimize it |
| mobile | React Native (Expo & CLI), push notifications, deep linking | one team, every platform |
| payments | Stripe, PayPal, LiqPay | money flows don't get "we'll fix it later" |
| infra | AWS, Docker, GitHub Actions, GitLab CI, Vercel, Supabase, Firebase | releases should be dull and repeatable |

### things I will not apologize for

- Asking "why" before a single line of TypeScript gets written - half of complex features shrink once we agree on the user outcome.
- Treating an API as a contract: consistent responses, predictable errors, real status codes, versioning when it breaks.
- Questioning every new dependency. Fewer isn't always better; intentional always is.
- Measuring before adding indexes. Then verifying the impact.
- Paying down tech debt. Having it is fine. Ignoring it is not.
